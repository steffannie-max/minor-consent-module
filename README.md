# Minor Consent to Behavioral Health Care — Module 1

GitHub-ready static learning module for Trauma Informed Oregon.

## Publish

1. Upload the full contents of this folder to a GitHub repository.
2. Keep `index.html`, `assets/`, `resources/`, and `tools/` in the same structure.
3. Add final narration files to `assets/audio/`.
4. In repository settings, enable GitHub Pages from the main branch/root.
5. Open the published URL and complete the final accessibility and media checks.

## Included

- Local TIO logo, Mandy Davis photo, opening video, and poster
- Keyboard, focus, reflow, reduced-motion, accordion, and reveal behavior
- Text alternatives beneath narrated slides
- In-memory-only reflection preservation; refresh or close resets entered information
- Certificate of Module Review with print/PDF and HTML save options
- Two accessible downloadable tipsheets
- Visible content-review date
- Official OHA and TIO resource links

## Narration

Narration files were not available in the working folder, so they are not included. Add them to `assets/audio/` using the filenames in `assets/audio/README.txt`.

The current text alternatives reflect visible slide content. Replace them with verbatim transcripts when final narration transcripts are available.

## Final accessibility testing

Before launch, test keyboard-only navigation, VoiceOver or NVDA, 200% and 400% zoom, mobile reflow, major browsers, every media segment, certificate printing, HTML validity, contrast, and automated accessibility checks.

This module is educational and is not legal advice.
